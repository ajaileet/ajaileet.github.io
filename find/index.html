SUID binary hunting — privilege escalation
find / -type f -perm /4000 -user root 2>/dev/null
Find all root-owned SUID binaries. Suppress permission errors. Classic first step in Linux privesc.
Find large files eating disk space
find / -type f -size +100M -exec ls -lh {} \; 2>/dev/null
List all files over 100 MB with human-readable sizes. Append | sort -rh to rank them.
Incident response — recently modified files
find /var/www /etc /tmp -type f -mtime -1 ! -path "*/proc/*" -ls
Files modified in the last 24h in web root, config, and temp dirs. Critical for IR triage.
Security audit — world-writable files
find / -type f -perm /o+w ! -path "*/proc/*" ! -path "*/sys/*" 2>/dev/null
Identify world-writable files — common misconfiguration in hardening audits and CTFs.
Delete files older than 30 days (safe pattern)
find /var/log/archive -type f -name "*.log" -mtime +30 -print -delete
Dry-run with -print first — remove it once verified. Safer than -delete alone.
Hunt for webshells in PHP files
find /var/www -type f -name "*.php" -print0 | xargs -0 grep -l "eval(base64"
-print0 + xargs -0 safely handles filenames with spaces. Classic webshell indicator.
Remove empty directories recursively
find . -type d -empty -delete
Clean up leftover empty folders after deployments or file operations.
Find orphaned files (no valid owner)
find /home /var -nouser -o -nogroup 2>/dev/null
Detect files left behind by deleted users — useful after account cleanup.
Fix web directory permissions (files + dirs)
find /var/www/html -type f -exec chmod 644 {} + && find /var/www/html -type d -exec chmod 755 {} +
Standard web hardening: 644 for files, 755 for directories. + batches for speed.
Find hidden files in home directories
find /home -maxdepth 3 -name ".*" -type f -ls
Discover .bash_history, .ssh/config, .env files for security review.
Hunt for private keys and credentials
find / -type f \( -name "id_rsa" -o -name "*.pem" -o -name "*.key" \) 2>/dev/null
Locate SSH private keys and certificates. Commonly found in CTF challenges and misconfigured servers.
Find executable files not in standard paths
find /tmp /var/tmp /dev/shm -type f -executable -ls 2>/dev/null
Malware and droppers often live in writable temp dirs. Check these during IR investigations.
Monitor config changes (SOC / FIM baseline)
find /etc -type f -newer /tmp/baseline_marker -not -name "*.swp" -printf "%T@ %p\n" | sort -n
Compare against a baseline file. Use touch /tmp/baseline_marker to set the reference point.
